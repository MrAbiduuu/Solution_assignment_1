# B8A1 – Assignment: Problem Solving with TypeScript & OOP

## Assignment Overview

This repository contains my solutions for the B8A1 assignment, focusing on problem-solving with TypeScript and Object-Oriented Programming (OOP).

The assignment covers fundamental TypeScript concepts, including basic types, optional parameters, union types, readonly tuples, interfaces, generics, type narrowing, Promises, classes, inheritance, and access modifiers.

## Problem Solving (50 Marks)

All eight coding problems are implemented in a single TypeScript file named `solutions.ts`.

The problems demonstrate:

1. Optional and default parameters.
2. Union types and type narrowing.
3. Readonly tuples.
4. Generics and rest parameters.
5. Interfaces and array filtering.
6. Generics with keyof constraints.
7. Classes, inheritance, and access modifiers.
8. Asynchronous programming with Promises.

## Blog Posts (10 Marks)

Two technical blog posts are included in this repository:

1. **[Type Aliases vs Interfaces in TypeScript](./type-vs-interface.md)**

   Explains the differences between type aliases and interfaces, their features, and when to use each.

2. **[Access Modifiers in TypeScript OOP](./access-modifiers.md)**

   Explains public, private, protected, and readonly access modifiers with practical code examples.

## How to Run

Install TypeScript:

```bash
npm install -g typescript
```

Check the TypeScript version:

```bash
tsc --version
```

Compile the solution:

```bash
tsc solutions.ts --noEmit --strict --target ES2020
```
